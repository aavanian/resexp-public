#+OPTIONS: toc:nil num:nil html-style:nil

* Introduction

Python is a versatile programming language perfect for beginners.

* Installation

** On macOS

#+BEGIN_SRC bash
brew install python3
#+END_SRC

** On Linux

#+BEGIN_SRC bash
sudo apt-get install python3

* Your First Program

Create a file called =hello.py=:

#+BEGIN_SRC python
def greet(name):
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(greet("World"))

Run it:

#+BEGIN_SRC bash
python3 hello.py
#+END_SRC

- Read the [[file:python-basics.org][Python Basics]] guide

Technical Reference Page

A more structured reference page: 

#+TITLE: API Functions Reference
#+OPTIONS: toc:2 num:nil html-style:nil

* Overview

This document describes all available API functions.

* Authentication Functions

** login(username, password)

Authenticate a user with credentials.

- *Parameters*
  - =username= (string): User's username
  - =password= (string): User's password
- *Returns*: Authentication token (string)
- *Throws*: =AuthenticationError= if credentials invalid

*Example:*

#+BEGIN_SRC python
token = login("alice", "secret123")
#+END_SRC

** logout(token)

Invalidate an authentication token.

- *Parameters*
  - =token= (string): Authentication token
- *Returns*: None

* Data Functions

** fetch_user(user_id)

Retrieve user information by ID.

- *Parameters*
  - =user_id= (integer): Unique user identifier
- *Returns*: User object with properties:
  - =id= (int): User ID
  - =name= (string): Full name
  - =email= (string): Email address
  - =created_at= (datetime): Account creation date

Tutorial Page

Step-by-step tutorial format: 

#+TITLE: Building a REST API
#+OPTIONS: toc:1 num:t html-style:nil

* Prerequisites

Before starting, ensure you have:

- Python 3.8 or higher
- pip package manager
- Basic understanding of HTTP

* Step 1: Set Up Project

Create a new directory and virtual environment:

#+BEGIN_SRC bash
mkdir my-api
cd my-api
python3 -m venv venv
source venv/bin/activate
#+END_SRC

* Step 2: Install Dependencies

#+BEGIN_SRC bash
pip install flask flask-restful
#+END_SRC

* Step 3: Create Basic API

Create =app.py=:

#+BEGIN_SRC python
from flask import Flask
from flask_restful import Resource, Api

app = Flask(__name__)
api = Api(app)

class HelloWorld(Resource):
    def get(self):
        return {'message': 'Hello, World!'}

api.add_resource(HelloWorld, '/')

if __name__ == '__main__':
    app.run(debug=True)
#+END_SRC

* Step 4: Test the API

Run the server:

#+BEGIN_SRC bash
python app.py
#+END_SRC

Test with curl:

#+BEGIN_SRC bash
curl http://localhost:5000/
#+END_SRC

Expected output:

#+BEGIN_SRC json
{
  "message": "Hello, World!"
}
#+END_SRC

Emacs Configuration

Basic Org Export Setup

Add to your .emacs or init.el: 

;; Org-mode HTML export configuration
(require 'ox-html)

;; Don't include default CSS
(setq org-html-head-include-default-style nil)

;; Don't include scripts
(setq org-html-head-include-scripts nil)

;; Use HTML5
(setq org-html-html5-fancy t)
(setq org-html-doctype "html5")

;; No validation link
(setq org-html-validation-link nil)

Custom Export Command

;; Custom export function
(defun my/org-export-to-docs ()
  "Export current org file to HTML body only in docs directory."
  (interactive)
  (let* ((base-name (file-name-sans-extension
                     (file-name-nondirectory (buffer-file-name))))
         (output-file (concat "../docs/" base-name ".html")))
    (org-html-export-to-html nil nil nil t)
    (rename-file (concat base-name ".html") output-file t)
    (message "Exported to %s" output-file)))

;; Bind to a key
(define-key org-mode-map (kbd "C-c e d") 'my/org-export-to-docs)

Batch Export Script

Create export-all-org.el: 

(require 'ox-html)

;; Configure export
(setq org-html-head-include-default-style nil)
(setq org-html-head-include-scripts nil)
(setq org-html-validation-link nil)

;; Export function
(defun batch-export-org-files ()
  "Export all .org files in current directory to HTML."
  (dolist (file (directory-files "." t "\\.org$"))
    (with-current-buffer (find-file-noselect file)
      (org-html-export-to-html nil nil nil t)
      (kill-buffer))))

(batch-export-org-files)

Use it: 

emacs --batch -l export-all-org.el --kill

Navigation Updates

Adding a New Page

In index.html, add to navigation: 

<ul class="nav-menu" id="navMenu">
    <!-- Existing items... -->

    <li class="nav-section">New Section</li>
    <li><a href="#" data-page="my-new-page">My New Page</a></li>
</ul>

Adding Subsections

Create nested navigation with CSS: 

<ul class="nav-menu">
    <li class="nav-section">Guides</li>
    <li><a href="#" data-page="intro">Introduction</a></li>

    <!-- Subsection -->
    <li style="padding-left: 20px;">
        <a href="#" data-page="intro-basics">Basics</a>
    </li>
    <li style="padding-left: 20px;">
        <a href="#" data-page="intro-advanced">Advanced</a>
    </li>
</ul>

Search Index Updates

Adding Pages to Search

In assets/js/search.js, update the index: 

searchIndex = [
    // ... existing entries ...

    {
        title: "Python Tutorial",
        url: "docs/python-tutorial.html",
        content: "python programming tutorial beginner guide installation hello world functions classes",
        excerpt: "Complete Python tutorial for beginners covering installation, basics, and first programs."
    },

    {
        title: "Advanced Python Patterns",
        url: "docs/python-advanced.html",
        content: "python advanced patterns decorators generators context managers metaclasses",
        excerpt: "Advanced Python programming patterns and best practices for experienced developers."
    }
];

Optimizing Search Keywords

Tips for effective search keywords:

  • Include synonyms: "tutorial guide walkthrough"
  • Add common typos: "python pyton"
  • Include abbreviations: "api application programming interface"
  • Add related terms: "install setup configure deployment"

Complete Workflow Example

  1. Create tutorial.org:

    #+TITLE: My Tutorial
#+OPTIONS: toc:nil num:nil html-style:nil

* Introduction
This is my tutorial content...

  2. Export in Emacs: C-c C-e h b

  3. Move to docs:

    mv tutorial.html docs/

  4. Update index.html navigation:

    <li><a href="#" data-page="tutorial">Tutorial</a></li>

  5. Update assets/js/search.js:

    {
    title: "Tutorial",
    url: "docs/tutorial.html",
    content: "tutorial guide introduction",
    excerpt: "Tutorial introduction"
}

  6. Test: Open index.html and verify!

Installation

This documentation system is designed to be simple and portable. There's no traditional "installation" required - just copy and use!

Requirements

The only requirement is a modern web browser that supports:

  • HTML5
  • CSS3
  • ES6 JavaScript
  • Fetch API

Any browser from the last 5 years should work perfectly, including:

  • Chrome/Chromium (version 60+)
  • Firefox (version 60+)
  • Safari (version 12+)
  • Edge (version 79+)

Setup

Option 1: USB Drive

  1. Copy the entire documentation folder to a USB drive
  2. Open index.html in your web browser
  3. Done! No server needed.

Option 2: Local Storage

  1. Copy the documentation folder to your computer
  2. Double-click index.html to open
  3. Bookmark the page for easy access

Option 3: Network Share

  1. Place the folder on a network share
  2. Team members can access via file:// protocol
  3. Everyone sees the same documentation

Browser Configuration

Important: Modern browsers have CORS security restrictions that may block loading local files via JavaScript.

Recommended: Use Simple Server

The easiest solution is to use the included Python server: 

python3 serve.py

Then open http://localhost:8000 in any browser. This avoids all file:// protocol restrictions.

Firefox (Best for Offline Use)

Works perfectly with file:// protocol! No configuration needed. Just double-click index.html.

Recommended for USB drives and offline deployment.

Chrome/Safari

These browsers block local file loading by default. Solutions:

  1. Use python3 serve.py (easiest)
  2. Use Firefox instead
  3. Start Chrome with flag: chrome --allow-file-access-from-files

Safari

  1. Open Safari Preferences
  2. Go to "Advanced" tab
  3. Enable "Show Develop menu"
  4. In Develop menu, disable "Local File Restrictions"

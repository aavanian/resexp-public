Welcome to the Documentation

This is a static documentation system designed to run entirely offline from a USB drive or local file system. No server required!

Features

  • Offline-First: Works perfectly from file:// protocol
  • Client-Side Search: Fast, built-in search functionality
  • No Dependencies: All assets embedded, no CDN links
  • Responsive Design: Works on desktop, tablet, and mobile
  • Long-Term Stability: Simple, maintainable code that will work for years

Getting Started

To get started with this documentation system:

  1. Navigate to the Installation guide
  2. Follow the Quick Start tutorial
  3. Explore the User Guide for detailed information

How It Works

This system uses pure HTML, CSS, and JavaScript with no external dependencies. The content is loaded dynamically from HTML files in the docs/ directory, which can be exported from Org-mode in Emacs.

Note: All content is indexed for search automatically. The search implementation is lightweight and fast, perfect for documentation use cases.

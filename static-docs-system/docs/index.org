* Welcome!

This is a static documentation system built entirely with *Org-mode*.

** Key Features

- ✅ *Pure Org-mode*: No build scripts, just export!
- ✅ *Shared CSS*: Consistent styling via =style.css=
- ✅ *Integrated Search*: Lunr.js search in navigation bar
- ✅ *Direct Links*: No CORS issues, works from =file://=
- ✅ *Responsive*: Works on all screen sizes
- ✅ *No Build Process*: Just export from Emacs

** How It Works

This system uses Org-mode's built-in HTML export with:

1. Shared CSS file (=style.css=)
2. Navigation bar with integrated search
3. Lunr.js for powerful search
4. Consistent export settings

** Getting Started

1. Read the [[file:setup.html][Setup Guide]]
2. See the [[file:example.html][Example Page]]
3. Try the search box above!
4. Start writing your own Org files

** The Simplicity

Each Org file is self-contained:

- Includes CSS via =#+HTML_HEAD=
- Includes search scripts
- Adds navigation via =#+BEGIN_EXPORT html=
- Exports to complete, standalone HTML
- *That's it!*

#+BEGIN_QUOTE
*No build process.* *No JavaScript complexity.* Just Org-mode doing what it does best, enhanced with lunr.js for great search.
#+END_QUOTE

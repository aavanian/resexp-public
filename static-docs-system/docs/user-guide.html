User Guide

Complete guide to using and customizing your static documentation system.

System Overview

This documentation system is built on three core principles:

  1. Simplicity: Pure HTML/CSS/JS, no build process
  2. Portability: Works from any location, even offline
  3. Longevity: No dependencies means it works for years

Components

Navigation System

The sidebar navigation (assets/js/navigation.js) handles:

  • Loading page content dynamically
  • Managing browser history (back/forward buttons)
  • Caching pages for faster subsequent loads
  • Highlighting the active page

Search System

The search functionality (assets/js/search.js) provides:

  • Real-time search as you type
  • Keyword highlighting in results
  • Title and content matching with scoring
  • Simple index format for easy updates

Styling

All CSS is embedded in index.html for:

  • No external file dependencies
  • Guaranteed consistent styling
  • Easy customization in one place

Customization

Changing Colors

Edit the CSS variables in index.html: 

:root {
    --primary-color: #2c3e50;      /* Dark blue-gray */
    --secondary-color: #3498db;    /* Bright blue */
    --background: #ffffff;         /* White */
    --sidebar-bg: #f8f9fa;        /* Light gray */
    --border-color: #dee2e6;      /* Border gray */
    --text-color: #333;           /* Dark text */
    --link-color: #3498db;        /* Link blue */
    --link-hover: #2980b9;        /* Darker blue */
    --code-bg: #f4f4f4;          /* Code background */
    --search-highlight: #fff3cd;  /* Yellow highlight */
}

Changing Layout

The sidebar width can be adjusted: 

.sidebar {
    width: 280px;  /* Change this value */
}

.main-content {
    margin-left: 280px;  /* Should match sidebar width */
}

Adding Custom Sections

To add a new section to the navigation: 

<li class="nav-section">My New Section</li>
<li><a href="#" data-page="my-page">My Page</a></li>

Org-mode Integration

Export Configuration

Create a .dir-locals.el file in your org documentation directory: 

((org-mode . ((org-html-doctype . "html5")
              (org-html-html5-fancy . t)
              (org-html-validation-link . nil))))

Batch Export Script

For exporting multiple files, create a bash script: 

#!/bin/bash
# export-all.sh

for file in *.org; do
    emacs "$file" \
        --batch \
        --eval "(progn (org-html-export-to-html nil nil nil t))" \
        --kill

    # Move to docs directory
    html_file="${file%.org}.html"
    mv "$html_file" ../docs/
done

Recommended Org Settings

For consistent exports, use these options in your Org files: 

#+OPTIONS: toc:nil num:nil html-style:nil html-scripts:nil
#+OPTIONS: html-postamble:nil
#+HTML_HEAD:

Best Practices

Content Organization

  • One topic per page: Keep pages focused
  • Clear hierarchy: Use headings consistently
  • Cross-link: Link related pages together
  • Examples: Include practical code examples

Search Optimization

When adding pages to the search index:

  • Include relevant keywords in content field
  • Write clear, descriptive excerpt text
  • Use the exact page title from your HTML

File Management

  • Keep source .org files in sample-org/
  • Export only to docs/ directory
  • Use version control (Git) to track changes

Troubleshooting

Page Won't Load

  • Check filename matches data-page attribute
  • Ensure file is in docs/ directory
  • Verify file has .html extension
  • Check browser console for errors

Search Not Finding Page

  • Verify page is in search index
  • Check keywords in content field
  • Try different search terms

Styling Issues

  • Ensure HTML is exported as "body only"
  • Remove any inline styles from Org export
  • Check for conflicting CSS in exported HTML

Advanced Topics

Adding Table of Contents

You can add a TOC to individual pages using Org-mode: 

#+OPTIONS: toc:2  # Two levels of headings

Syntax Highlighting

Org-mode can export code blocks with syntax highlighting. Configure in Emacs: 

(setq org-html-htmlize-output-type 'inline-css)

Adding Images

  1. Create assets/images/ directory
  2. Store images there
  3. Reference in Org-mode: [[file:../assets/images/my-image.png]]

Maintenance

This system requires minimal maintenance:

  • Update content: Just export new HTML from your Org files
  • Add pages: Follow the quick start process
  • Backup: Copy the entire folder periodically
  • No updates needed: The code is stable and dependency-free

* Introduction

This guide shows you how to create documentation pages using pure Org-mode export.

* Quick Start

** Step 1: Create a New Org File

Create a new file in the =docs/= directory:

#+BEGIN_EXAMPLE
docs/my-page.org
#+END_EXAMPLE

** Step 2: Add the Standard Header

Copy this header to the top of your file:

#+BEGIN_EXAMPLE
,#+TITLE: My Page Title
,#+OPTIONS: toc:nil num:nil html-style:nil html-scripts:nil
,#+HTML_HEAD: <link rel="stylesheet" type="text/css" href="../style.css" />
,#+HTML_HEAD: <style>body { max-width: 900px; margin: 0 auto; padding: 20px; }</style>

,#+BEGIN_EXPORT html
<div class="nav-bar">
  <h1>📚 Documentation</h1>
  <ul class="nav-links">
    <li><a href="index.html">Home</a></li>
    <li><a href="setup.html">Setup Guide</a></li>
    <li><a href="my-page.html">My Page</a></li>
    <li><a href="example.html">Example Page</a></li>
    <li><a href="../search.html">Search</a></li>
  </ul>
</div>
,#+END_EXPORT
#+END_EXAMPLE

** Step 3: Write Your Content

Use normal Org-mode syntax:

#+BEGIN_EXAMPLE
,* My First Section

Some content here...

,** A Subsection

More content...

,#+BEGIN_SRC python
def hello():
    print("Hello, World!")
,#+END_SRC
#+END_EXAMPLE

** Step 4: Export to HTML

In Emacs:

1. Open your =.org= file
2. Press =C-c C-e= (export dispatcher)
3. Press =h= for HTML
4. Press =h= again for "export to HTML"

This creates =my-page.html= in the same directory.

** Step 5: View in Browser

Open the generated HTML file in any browser!

* Header Options Explained

Let's break down each line in the header:

** Title

#+BEGIN_EXAMPLE
,#+TITLE: My Page Title
#+END_EXAMPLE

Sets the page title (appears in browser tab and as H1).

** Export Options

#+BEGIN_EXAMPLE
,#+OPTIONS: toc:nil num:nil html-style:nil html-scripts:nil
#+END_EXAMPLE

- =toc:nil= - No table of contents (or use =toc:t= to include one)
- =num:nil= - No section numbering
- =html-style:nil= - Don't include default Org CSS
- =html-scripts:nil= - Don't include default Org JavaScript

** CSS Include

#+BEGIN_EXAMPLE
,#+HTML_HEAD: <link rel="stylesheet" type="text/css" href="../style.css" />
#+END_EXAMPLE

Links to the shared CSS file. Adjust path based on file location:
- =../style.css= if file is in =docs/= subdirectory
- =style.css= if file is in root directory

** Body Styles

#+BEGIN_EXAMPLE
,#+HTML_HEAD: <style>body { max-width: 900px; margin: 0 auto; padding: 20px; }</style>
#+END_EXAMPLE

Inline styles for page layout. Centers content with max width.

** Navigation Bar

#+BEGIN_EXAMPLE
,#+BEGIN_EXPORT html
<div class="nav-bar">
  <h1>📚 Documentation</h1>
  <ul class="nav-links">
    <li><a href="index.html">Home</a></li>
    <li><a href="setup.html">Setup Guide</a></li>
    <li><a href="example.html">Example</a></li>
    <li><a href="../search.html">Search</a></li>
  </ul>
</div>
,#+END_EXPORT
#+END_EXAMPLE

Adds a navigation bar at the top. Update links when adding new pages.

* Customization

** Changing Colors

Edit =style.css= and modify the CSS variables:

#+BEGIN_SRC css
:root {
    --primary: #2c3e50;
    --secondary: #3498db;
    --bg: #ffffff;
    /* ... */
}
#+END_SRC

** Adding New Pages

1. Create new =.org= file with standard header
2. Add link to navigation bar in *all* existing pages
3. Export to HTML
4. Update =search.html= index (see below)

** Table of Contents

To include a table of contents, change the options:

#+BEGIN_EXAMPLE
,#+OPTIONS: toc:t num:nil
#+END_EXAMPLE

This will auto-generate a TOC from your headings.

* Search Functionality

The =search.html= page provides simple client-side search.

** Updating the Search Index

Edit =search.html= and update the =pages= array:

#+BEGIN_SRC javascript
const pages = [
    {
        title: "My New Page",
        url: "docs/my-new-page.html",
        keywords: "relevant search keywords here"
    }
];
#+END_SRC

* Tips & Best Practices

** File Organization

#+BEGIN_EXAMPLE
static-docs-system/
├── style.css           # Shared CSS
├── search.html         # Search page
├── docs/
│   ├── index.org       # Source files
│   ├── index.html      # Generated files
│   ├── setup.org
│   ├── setup.html
│   └── ...
#+END_EXAMPLE

** Keep Source Files

- Keep =.org= files for editing
- Export to =.html= for distribution
- For deployment, only copy =.html= files and =style.css=

** Version Control

Add to =.gitignore=:

#+BEGIN_EXAMPLE
*.html
#+END_EXAMPLE

Only commit =.org= source files and =style.css=.

Or commit both source and generated files for convenience.

** Consistent Navigation

Create a template file with the standard header, copy/paste for new pages.

** Code Syntax Highlighting

For syntax highlighted code blocks, install =htmlize= in Emacs:

#+BEGIN_EXAMPLE
M-x package-install RET htmlize RET
#+END_EXAMPLE

Then configure:

#+BEGIN_SRC elisp
(setq org-html-htmlize-output-type 'inline-css)
#+END_SRC

* Deployment

** USB Drive

1. Export all =.org= files to HTML
2. Copy all =.html= files and =style.css= to USB
3. Users open =docs/index.html=

** Network Share

1. Export all files
2. Place on shared drive
3. Team accesses via =file://= path

** Web Server (Optional)

While designed for offline use, you can also serve on the web:

#+BEGIN_SRC bash
python3 -m http.server 8000
#+END_SRC

Then open =http://localhost:8000/docs/index.html=

* Troubleshooting

** CSS Not Loading

Check the path in =#+HTML_HEAD=:
- Use =../style.css= from subdirectories
- Use =style.css= from root
- Use absolute paths if needed: =file:///full/path/to/style.css=

** Links Not Working

- Use =.html= extension in links, not =.org=
- Example: =[[file:other-page.html][Link]]=

** Search Not Finding Pages

Update the search index in =search.html= when adding pages.

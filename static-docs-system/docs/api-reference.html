API Reference

Technical reference for the JavaScript API used in this documentation system.

Navigation API

Defined in assets/js/navigation.js

loadContent(page)

Load content for a specific page.

Parameters:

  • page (string): Page identifier (filename without .html extension)

Example:

loadContent('user-guide');
// Loads docs/user-guide.html into content frame

updateActiveNav(activeLink)

Update which navigation link is highlighted as active.

Parameters:

  • activeLink (HTMLElement): The link element to mark as active

handleNavClick(event)

Event handler for navigation menu clicks.

Parameters:

  • event (Event): Click event object

loadFromHash()

Load page based on URL hash fragment.

Example:

// URL: file:///.../index.html#quick-start
loadFromHash();
// Loads the quick-start page

Search API

Defined in assets/js/search.js

initializeSearchIndex()

Initialize the search index with document metadata.

Returns: void

performSearch(query)

Search indexed documents for a query string.

Parameters:

  • query (string): Search query text

Returns: Array of result objects

Result object structure:

{
    title: "Page Title",
    url: "docs/page.html",
    content: "searchable content",
    excerpt: "Brief description",
    score: 25  // Relevance score
}

Example:

const results = performSearch('installation guide');
// Returns array of matching pages, sorted by relevance

displaySearchResults(results, query)

Display search results in the UI.

Parameters:

  • results (Array): Array of search result objects
  • query (string): Original search query for highlighting

hideSearchResults()

Hide the search results dropdown.

highlightSearchTerms(text, query)

Add HTML highlighting to matching search terms.

Parameters:

  • text (string): Text to highlight
  • query (string): Search query

Returns: HTML string with highlighted terms

Example:

const highlighted = highlightSearchTerms(
    'Installation instructions',
    'install'
);
// Returns: '<span class="search-highlight">Install</span>ation instructions'

Data Structures

Search Index Entry

Each entry in the search index should have this structure: 

{
    title: string,      // Page title (displayed in results)
    url: string,        // Relative path to HTML file
    content: string,    // Space-separated keywords for searching
    excerpt: string     // Brief description (shown in results)
}

Example:

{
    title: "API Reference",
    url: "docs/api-reference.html",
    content: "api reference documentation functions methods classes",
    excerpt: "Complete API documentation for all available functions."
}

Content Cache

Loaded pages are cached in the contentCache object: 

// Key: page identifier
// Value: HTML content string
{
    "welcome": "<h1>Welcome</h1><p>...</p>",
    "installation": "<h1>Installation</h1>..."
}

HTML Attributes

data-page

Used on navigation links to specify which page to load.

Example:

<a href="#" data-page="user-guide">User Guide</a>

Loads docs/user-guide.html when clicked.

CSS Classes

Navigation Classes

  • .sidebar - Main sidebar container
  • .nav-menu - Navigation menu list
  • .nav-section - Section header in navigation
  • .active - Currently selected navigation item

Search Classes

  • .search-container - Search box wrapper
  • .search-box - Search input field
  • .search-results - Search results dropdown
  • .search-result-item - Individual result item
  • .search-highlight - Highlighted search terms

Content Classes

  • .main-content - Main content area
  • .content-frame - Content container
  • .loading - Loading state indicator

CSS Variables

Customize appearance by modifying these CSS custom properties: 

--primary-color       /* Main heading color */
--secondary-color     /* Links and accents */
--background          /* Page background */
--sidebar-bg          /* Sidebar background */
--border-color        /* Border colors */
--text-color          /* Body text color */
--link-color          /* Link color */
--link-hover          /* Link hover color */
--code-bg             /* Code block background */
--search-highlight    /* Search highlight color */

Events

DOMContentLoaded

Both navigation and search initialize on this event: 

document.addEventListener('DOMContentLoaded', function() {
    // Initialize search index
    initializeSearchIndex();

    // Set up navigation handlers
    // Load initial page
    loadFromHash();
});

popstate

Handles browser back/forward navigation: 

window.addEventListener('popstate', function(e) {
    // Load page from browser history
});

Browser Compatibility

Required browser features:

  • Fetch API: For loading page content
  • History API: For back/forward navigation
  • CSS Custom Properties: For theming
  • ES6 Features: Arrow functions, const/let, template literals

Compatible with:

  • Chrome/Edge 60+
  • Firefox 60+
  • Safari 12+
  • Opera 47+

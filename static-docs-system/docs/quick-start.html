Quick Start Guide

Get your documentation up and running in minutes!

Step 1: Write Content in Org-mode

Create your documentation in Emacs using Org-mode. Here's a simple example: 

#+TITLE: My Documentation Page
#+OPTIONS: toc:nil num:nil html-style:nil

* Introduction

This is my documentation content.

** Features

- Feature one
- Feature two
- Feature three

** Code Example

#+BEGIN_SRC python
def hello_world():
    print("Hello, World!")
#+END_SRC

Step 2: Export to HTML

In Emacs, export your Org file to HTML body only:

  1. Open your .org file in Emacs
  2. Press C-c C-e to open the export dispatcher
  3. Press h for HTML export
  4. Press b for "body only" export

This creates a clean HTML file without <html>, <head>, or <body> tags - just the content.

Step 3: Add to Documentation

  1. Save the exported HTML file to the docs/ directory
  2. Name it descriptively, e.g., my-feature.html

Step 4: Update Navigation

Edit index.html and add your page to the navigation menu: 

<ul class="nav-menu" id="navMenu">
    <!-- Add your page here -->
    <li><a href="#" data-page="my-feature">My Feature</a></li>
</ul>

The data-page attribute should match your filename without the .html extension.

Step 5: Update Search Index

Edit assets/js/search.js and add your page to the search index: 

searchIndex = [
    // ... existing entries ...
    {
        title: "My Feature",
        url: "docs/my-feature.html",
        content: "keywords describing your content",
        excerpt: "Brief description of the page"
    }
];

Step 6: Test

  1. Open index.html in your browser
  2. Click on your new page in the navigation
  3. Try searching for keywords from your page

Tips for Success

Org-mode Export Settings

Add these settings at the top of your Org files for optimal export: 

#+OPTIONS: toc:nil          # No table of contents
#+OPTIONS: num:nil          # No section numbers
#+OPTIONS: html-style:nil   # No inline styles
#+OPTIONS: html-scripts:nil # No scripts

File Naming

  • Use lowercase with hyphens: user-guide.html
  • Be descriptive: api-authentication.html not auth.html
  • Keep names short but clear

Content Organization

  • Start with a clear H1 heading
  • Use H2 and H3 for subsections
  • Include code examples where helpful
  • Add links to related pages

Example Workflow

Here's a complete example workflow:

  1. Create tutorial.org in Emacs
  2. Write your content using Org-mode syntax
  3. Export: C-c C-e h b (HTML body only)
  4. Move tutorial.html to docs/ folder
  5. Update navigation in index.html
  6. Update search index in assets/js/search.js
  7. Open and test!

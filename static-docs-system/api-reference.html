API Reference

Technical reference for the documentation system.

Build Script

build.py

Main build script that generates pages from template and content.

Functions:

read_file(path)

Read file content.

  • Parameters: path (Path) - File path
  • Returns: str - File content

build_page(page_id, title, content_html, template)

Build a complete HTML page from template.

  • Parameters:
    • page_id (str) - Page identifier
    • title (str) - Page title
    • content_html (str) - HTML content
    • template (str) - Template HTML
  • Returns: str - Complete HTML page

Template Placeholders

The template uses these placeholders:

Placeholder Description
{{TITLE}} Page title
{{CONTENT}} Main content from Org export

Search JavaScript

performSearch(query)

Search indexed documents.

  • Parameters: query (string) - Search query
  • Returns: Array - Matching results with scores

highlightText(text, query)

Add highlighting to matching terms.

  • Parameters:
    • text (string) - Text to highlight
    • query (string) - Search query
  • Returns: string - HTML with highlights

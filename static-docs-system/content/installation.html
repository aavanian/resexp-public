Installation

There's no traditional "installation" - just download and use!

Requirements

Any modern web browser:

  • Chrome/Chromium 60+
  • Firefox 60+
  • Safari 12+
  • Edge 79+

Setup Options

Option 1: USB Drive

  1. Copy the entire folder to a USB drive
  2. Double-click index.html
  3. Done!

Option 2: Local Storage

  1. Copy the folder to your computer
  2. Double-click index.html to open
  3. Bookmark for easy access

Option 3: Network Share

  1. Place folder on network share
  2. Team members access via file:// protocol

Why This Works

Unlike other documentation systems, this one uses direct HTML links instead of JavaScript to load content. This means:

  • ✅ No CORS issues
  • ✅ Works in ALL browsers
  • ✅ No configuration needed
  • ✅ True offline capability

User Guide

Complete guide to using and customizing your static documentation system.

System Architecture

This system consists of:

  • Template (templates/page-template.html) - Base HTML structure
  • Content (content/*.html) - Your documentation (from Org-mode)
  • Build Script (build.py) - Generates complete pages
  • Pages (*.html) - Complete, standalone HTML files

How It Works

  1. Write content in Org-mode
  2. Export to HTML (body only)
  3. Place in content/ directory
  4. Run python3 build.py
  5. Complete pages are generated with template, navigation, and search

Customization

Changing Colors

Edit CSS variables in templates/page-template.html:

:root {
    --primary: #2c3e50;
    --secondary: #3498db;
    --bg: #ffffff;
    /* ... more colors ... */
}

Adding New Pages

  1. Create content in content/new-page.html
  2. Add to nav menu in template
  3. Add to build script pages list
  4. Add to search index in template
  5. Run python3 build.py

Search System

Search index is embedded in each page. To add pages to search:

Edit the searchIndex array in templates/page-template.html:

const searchIndex = [
    {
        title: "My Page",
        url: "my-page.html",
        content: "keywords for searching",
        excerpt: "Brief description"
    }
];

Deployment

Just copy the generated *.html files (not the source files!) to your deployment location:

  • USB drive
  • Network share
  • Zip file for distribution

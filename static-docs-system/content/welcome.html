Welcome to the Documentation

This is a standalone static documentation system designed to run entirely offline from a USB drive or local file system. No server required!

Key Features

  • Offline-First: Works perfectly from file:// protocol
  • No CORS Issues: Uses direct HTML links, not JavaScript loading
  • Client-Side Search: Fast built-in search functionality
  • No Dependencies: All assets embedded, no CDN links
  • Responsive Design: Works on desktop, tablet, and mobile
  • Org-mode Integration: Export directly from Emacs

How It Works

This system uses a simple but robust approach:

  1. Each page is a complete, standalone HTML file
  2. Navigation uses normal <a href="page.html"> links
  3. Search is embedded JavaScript on each page
  4. No dynamic file loading = no CORS issues!

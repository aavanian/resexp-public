** Python

#+BEGIN_SRC python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
#+END_SRC

** JavaScript

#+BEGIN_SRC javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet('World'));
#+END_SRC

Build Script Example

Adding a new page to the build script:

pages = [
    # Existing pages
    ('index', 'Welcome', 'content/welcome.html', 'index.html'),
    
    # Your new page
    ('my-tutorial', 'My Tutorial', 'content/my-tutorial.html', 'my-tutorial.html'),
]

Workflow Example

# 1. Create Org file
emacs sample-org/tutorial.org

# 2. Export to HTML body only
# In Emacs: C-c C-e h b

# 3. Move to content directory
mv tutorial.html content/

# 4. Update template navigation
# Edit templates/page-template.html

# 5. Update build script
# Edit build.py

# 6. Build pages
python3 build.py

# 7. Open and test
open index.html

Quick Start Guide

Get your documentation up and running in minutes!

Step 1: Write Content in Org-mode

Create your documentation in Emacs using Org-mode: 

#+TITLE: My Documentation Page
#+OPTIONS: toc:nil num:nil html-style:nil

* Introduction

This is my documentation content.

** Features

- Feature one
- Feature two

** Code Example

#+BEGIN_SRC python
def hello():
    print("Hello, World!")
#+END_SRC

Step 2: Export to HTML

In Emacs, export your Org file to HTML body only:

  1. Open your .org file in Emacs
  2. Press C-c C-e to open export dispatcher
  3. Press h for HTML export
  4. Press b for "body only"

This creates clean HTML without <html>, <head>, or <body> tags.

Step 3: Add to Content Directory

  1. Save the exported HTML to the content/ directory
  2. Name it descriptively, e.g., my-feature.html

Step 4: Update Template Navigation

Edit templates/page-template.html and add your page to the nav menu: 

<ul class="nav-menu">
    <!-- Add your page here -->
    <li><a href="my-feature.html">My Feature</a></li>
</ul>

Step 5: Update Build Script

Edit build.py and add your page to the pages list: 

pages = [
    # ... existing pages ...
    ('my-feature', 'My Feature', 'content/my-feature.html', 'my-feature.html'),
]

Step 6: Build and Test

python3 build.py

Then open index.html in your browser!

* Introduction

This is an example Org-mode file demonstrating how to write documentation
that will be exported to HTML for the static documentation system.

** Purpose

This file shows:
- Basic Org-mode syntax
- How to structure content
- Code examples
- Export settings

* Writing Content

** Headings

Use asterisks for headings:
- =*= for level 1 (H1)
- =**= for level 2 (H2)
- =***= for level 3 (H3)

** Text Formatting

- *Bold text* with =*bold*=
- /Italic text/ with =/italic/=
- =Code text= with ~=code=~
- +Strikethrough+ with =+strikethrough+=

** Lists

Unordered lists use dashes or asterisks:

- First item
- Second item
  - Nested item
  - Another nested item
- Third item

Ordered lists use numbers:

1. First step
2. Second step
3. Third step

* Code Examples

** Inline Code

Use =code= for inline code, like =print("hello")= or =def function()=.

** Code Blocks

For multi-line code, use source blocks:

#+BEGIN_SRC python
def fibonacci(n):
    """Calculate Fibonacci number."""
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

# Example usage
for i in range(10):
    print(f"fib({i}) = {fibonacci(i)}")
#+END_SRC

You can specify the language for syntax highlighting:

#+BEGIN_SRC javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet('World'));
#+END_SRC

#+BEGIN_SRC bash
#!/bin/bash
# Example shell script

for file in *.org; do
    echo "Processing: $file"
done
#+END_SRC

** Exporting to HTML

In Emacs:

1. Open your =.org= file
2. Press =C-c C-e= to open export dispatcher
3. Press =h= for HTML export
4. Press =b= for "body only"

This creates clean HTML with just the content.

** Why "Body Only"?

The "body only" export is crucial because:
- Creates clean HTML without full page structure
- No conflicting styles
- Integrates seamlessly with the documentation template
- Smaller file size

* Best Practices

** File Organization

- Keep source =.org= files in =sample-org/= directory
- Export HTML files to =content/= directory
- Use descriptive filenames: =user-authentication.org=

** Content Structure

1. Start with clear H1 title
2. Use H2 for main sections
3. Use H3 for subsections
4. Keep hierarchy consistent

** Writing Style

- Be concise and clear
- Use examples liberally
- Include code snippets
- Link to related pages

* Complete Workflow

After writing your Org file:

1. Export to HTML (body only): =C-c C-e h b=
2. Move HTML to =content/= directory
3. Update navigation in =templates/page-template.html=
4. Update build script =build.py=
5. Update search index in template
6. Run =python3 build.py=
7. Test by opening generated HTML file

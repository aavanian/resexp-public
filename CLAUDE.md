# Research & Experiments Repository

## Purpose

This repository contains development research and experiment projects. Each project serves to:

- **Demonstrate** specific techniques, patterns, or technologies
- **Assess** technology and stack choices for future implementations
- **Understand** how to accomplish particular tasks
- **Identify** potential hurdles and challenges before committing to production implementations

## Project Structure

Each experiment or research project should be self-contained and include:
- Clear documentation of what is being tested/assessed
- Results and findings from the experiment
- Notes on challenges encountered
- Recommendations for or against the tested approach

## Python Standards

All Python projects in this repository must use:

- **[uv](https://github.com/astral-sh/uv)** - For Python package and project management
- **[ruff](https://github.com/astral-sh/ruff)** - For linting and formatting

No other Python package managers or linters should be used.

## Usage

This is an experimental repository. Code here is for learning and assessment purposes and should not be considered production-ready without proper review and refactoring.
